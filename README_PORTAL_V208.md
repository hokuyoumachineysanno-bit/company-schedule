# 社内業務ポータル v2.0.8

## 案件とタスク
- 案件＝仕事全体の箱
- タスク＝人と時間への割当
- 案件予定工数 / タスク割当済工数 / 未割当工数を表示
- 「残り○hを予定に入れる」で、残工数を初期値にしたタスクを作成
- 一発案件はそのまま1タスク化、複雑案件は必要なだけタスク分割可能

## タスク表示名
1. 内容入力あり → 入力内容
2. 内容空欄＋案件あり → 案件名
3. 内容空欄＋案件なし＋緊急 → 緊急対応
4. 内容空欄＋案件なし → 予定
旧データの「未記入」は空欄へ移行。

## 客先所在地
- 客先タスクで案件を選ぶと、納品先名＋納品先住所を自動入力
- タスク単位で自由に上書き可能
- 「納品先住所に戻す」あり

## 時間
- 開始時刻 30分単位
- 予定工数 0.5h単位
- ±30分ボタン
- 旧15分単位工数は起動時に0.5h単位へ丸める

## 仮顧客
- 納品先・支払先とも「仮入力」に切替可能
- 顧客マスタ登録前でも案件作成可能
- 仮入力は顧客名必須、住所任意

## 緊急
- 内容空欄なら「緊急対応」
- 日フォーカスの時間バーは区分に関係なく赤色
