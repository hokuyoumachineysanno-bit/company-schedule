# 社内予定・案件管理 v0.5.3

## 重要修正
- iPhone Safariで停止する可能性があったDOM参照を全面修正
- CSS/JSにバージョン文字列を付けてブラウザキャッシュを回避
- スマホ用レスポンシブUIはv0.5.2を継承
- 日タスクの追加・編集・削除、日送りもスマホから操作可能


## v0.5.2 追加
- iPhone / スマホ向けレスポンシブ表示
- 上部タブを横スワイプ対応
- 入力フォームをスマホでは1列表示
- 案件 / タスク / 休日一覧を横スクロール対応
- 日フォーカスの時間バーを横スワイプ対応
- 時間バーの氏名・車両列をスマホで固定表示
- タップしやすいボタン・入力サイズへ調整
- iPhone Safariの文字自動拡大を抑制

## v0.5.1 追加
- 日フォーカスのタスクを後から編集
- 時間、担当、車両、案件、状態、種別、タスク名を変更可能
- 編集後は年 / 四半期 / 月 / 日へ同じデータとして反映

## v0.5 追加
- 日フォーカスで前日・翌日へ移動
- 月フォーカスで前月・翌月へ移動
- 月の日付クリックから日フォーカスへ移動
- 法定休日 / 所定休日の登録
- 休日を月 / 日へ反映
- 案件の新規登録
- 案件の編集
- 案件ID変更時、関連予定も新しい案件IDへ追従
- 案件削除
- 案件から日予定追加へ移動
- localStorage 保存
