## 勤怠 v8.0との連携方針
現段階ではサンプル勤怠データです。
Firebase化時に以下を共通データとして扱う想定です。

- employees（社員マスタ）
- companyCalendar（会社カレンダー）
- attendanceRecords（勤怠実績）
- attendanceSummary（年・四半期・月集計）

予定管理側は社員ID・日付をキーに勤怠情報を読む構成にします。
