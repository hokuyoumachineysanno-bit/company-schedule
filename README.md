# 社内予定・案件管理 v0.3

GitHub Pages向けの静的プロトタイプです。

## 特徴
- 年 / 四半期 / 月 / 日を同じタスクデータから表示
- 確定 / 確認待ち / 仮予定 / 未割当を全ビューで共通表示
- 確認待ち・仮予定・未割当は点滅
- 日ビューから予定追加・削除
- localStorage保存（ブラウザ内のみ）

## GitHub Pages
1. このフォルダの中身をGitHubリポジトリへアップロード
2. Settings → Pages
3. Deploy from a branch
4. main / root を選択
