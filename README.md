# 社内業務ポータル v1.0
- タスク：客先案件 / 社内案件 / その他
- 案件を選び、その下に内容を自由記入
- 補助者は時間バーへ自動反映
- 緊急フラグ、事後入力対応
- 日延べ / ペンディング / 削除
- 日延べ理由と原因緊急タスクを記録
- 案件ステータス：情報→アプローチ→商談中→見積提出→受注→施工中→検収待ち→検収済→アフター→完了
- 24時間対応：午前0-12 / 午後12-24 / 終日0-24
- 深夜0-5、早朝5-8:30、基準8:30-17:30、夜間17:30-22、深夜22-24
- スマホ編集モーダルをスクロール可能なボトムシートへ修正
- 移動入力は一旦通常UIから外す方針
