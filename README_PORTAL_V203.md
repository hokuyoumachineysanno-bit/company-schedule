# 社内業務ポータル v2.0.3

## 時間バー修正
- バー位置計算と背景目盛を同じ時間軸へ統一
- 終日: 0-24時を1時間刻み（24列）
- 午前: 0-12時を1時間刻み（12列）
- 午後: 12-24時を1時間刻み（12列）
- 半日表示で数字が2段になっていた不具合を修正
- 13:00開始は13:00位置に表示

## 色
- 客先案件: 青
- 社内案件: 緑
- その他: 黄
- 仮予定: 元のカテゴリ色を維持したまま点線 + 点滅
- 緊急: 赤枠を併用

## ペンディング / 未割当
「未割当」を「ペンディング」に統合。
意味: 対応対象・受注済み等だが、まだ日程に配置できていない状態。

- 専用「ペンディング」タブを追加
- 日 / 月 / 四半期 / 年にミニ一覧を表示
- ペンディングは時間バーには表示しない
- 一覧から編集して、日付・時間を決めて確定へ戻せる
