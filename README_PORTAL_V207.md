# 社内業務ポータル v2.0.7

## 顧客マスタ
- `納入先コード.xls` の706件を組込
- 顧客コードは元Excelをそのまま使用
- 新規追加は既存体系に準じて3桁16進数で自動採番
  - 現在の最終 2C3 → 次は 2C4
- 顧客検索対応
- Excel出力対応

保持項目:
顧客コード / 納入先名 / フリガナ / 郵便番号 / 住所1 / 住所2 / TEL / FAX / 担当者

## 案件
- 納品先と支払先を分離
- 代理店が支払先になる案件に対応
- 支払先=納品先のチェックあり
- 顧客検索あり
- 案件一覧Excel出力
- 検収済以降はアーカイブ表示を維持

## ペンディング
- Excel出力
- 納品先 / 支払先 / 予定工数などを出力

## 既存データ
既存localStorageは消しません。
起動時にExcel顧客を不足分だけマージします。
