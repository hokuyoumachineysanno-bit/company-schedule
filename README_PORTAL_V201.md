# 社内業務ポータル v2.0.1 修正版

## 原因
v2.0ではTIMEスナップショット取込処理が `db` 初期化前に動いてしまい、
JavaScriptが ReferenceError で停止していました。

## 修正
- db初期化後にTIMEスナップショットを取り込む
- TIME勤怠は参照専用
- TIME暦（法定休日 / 所定休日 / 会社休業日）をポータル休日表示へ変換
- ページ復帰・TIMEキャッシュ更新時に再読込
- ポータル独自の案件・予定・マスタ編集はそのまま

## 反映先
`company-schedule` リポジトリだけに上書きしてください。
TIME v9.0側は変更不要です。
