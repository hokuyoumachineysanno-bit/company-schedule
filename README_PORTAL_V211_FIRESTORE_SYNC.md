# 社内業務ポータル v2.1.1 Firestore同期版

## 初回移行
1. 必ず既存データが入っているPCで開く。
2. Googleログイン後、ヘッダーの「このPCのデータをクラウドへ初回登録」を押す。
3. 件数を確認してOK。
4. 初回登録完了後、スマホ側を再読み込みする。
5. 以降は保存操作のたびにFirestoreへ同期する。

## 安全策
- Firestoreに共有データが未作成の間は、自動アップロードしない。
- 初回登録前のPCデータを localStorage の `companyPortalV06_backup_before_cloud` に退避する。
- Firestore `users/{uid}` の `active:true` がないGoogleアカウントはポータルを開けない。
- 共有データは `portalData/state` に保存する。

## 同期方式
v2.1.1ではポータルDB全体を1つの共有状態として同期する方式。
他端末の更新を検知した場合はローカルDBを書き換え、ページを自動再読み込みして反映する。
同時編集の競合は「最後に保存された端末」が優先される。
