# 社内業務ポータル v2.0.6

## 日フォーカス 人員並び
- 専務を最下段に固定
- 社長を下から2段目に固定
- その他社員は、その日の一番早い配置タスクを基準に並び替え
- 同じ最初のタスクへ入る社員は上下に連続配置

## 案件バーの「重さ」
同じタスクに主担当+補助が2人なら2段、3人なら3段の連続した縦バーとして表示。
人員投入量をバーの縦厚みで把握できます。
午後に別案件へ分かれた場合は、同じ社員行の午後部分に別のバーを描画します。

## 月フォーカス休日
- 法定休日: 濃いめの薄赤 + 赤い上帯 + 法定休日ラベル
- 所定休日: 濃いめの薄紫 + 紫の上帯 + 所定休日ラベル
- CSS対象を実際の month DOM (`daycell`) に修正

## 休日登録
名称自由入力を廃止し、所定休日 / 法定休日の2択のみ。
