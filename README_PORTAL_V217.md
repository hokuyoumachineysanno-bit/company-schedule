## セキュリティ上の重要事項
現在のGitHub Pages + localStorage + customer-master-data.js方式に、JavaScriptだけのパスワード画面を付けても顧客情報は保護できません。
スマホから社外アクセス可能にする段階では、認証とデータ保存をサーバー側へ移す必要があります。
推奨: Firebase Authentication + Firestore + Firebase Hosting（または同等の認証付き構成）。
